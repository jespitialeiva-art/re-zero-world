
# Re:Zero World

## Descripcion

Re:Zero World es una aplicacion desarrollada con Flutter
y Dart, inspirada en el anime Re:Zero.

El proyecto fue realizado como parte del Taller Practico
de Desarrollo Movil.

## Funcionalidades

### Home
- Publicaciones de Subaru y Emilia.
- Botones de Me gusta y comentarios.
- Banner informativo.
- Carrusel horizontal de personajes.

### Chats
- Lista de cinco conversaciones.
- Imagen, nombre y ultimo mensaje.
- Hora e indicador de mensajes sin leer.

### Laboratorio de widgets
- Contador de puntos de mana.
- Botones para aumentar y disminuir el valor.
- Actualizacion de la interfaz con setState().
- Limites entre 0 y 100.

## Tecnologias

- Flutter
- Dart

## Ejecucion

1. Tener instalado Flutter y sus herramientas.
2. Descargar o clonar este repositorio.
3. Abrir el proyecto en un editor compatible.
4. Ejecutar `flutter pub get`.
5. Ejecutar `flutter run` con un dispositivo disponible.

## Informacion adicional

Los datos son estaticos y se encuentran directamente
en el codigo.

La aplicacion no utiliza bases de datos, APIs ni
servicios externos.
